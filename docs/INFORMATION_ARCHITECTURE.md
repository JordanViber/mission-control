# Information Architecture

## Primary shell

A left side-nav drives the product.

### 1. Dashboard
High-level summary:
- active projects
- team health
- open tasks
- next scheduled jobs
- recent docs/memory updates

### 2. Task Board
Views:
- global kanban
- by project
- by assignee
- by worker type

### 3. Team
Views:
- org chart
- worker cards
- reporting lines
- role responsibilities
- session health

### 4. Memory
Views:
- search
- recent memory entries
- daily logs
- curated long-term memory
- by project / by person / by topic

### 5. Cron & Calendar
Views:
- all schedules
- by project
- by owner
- calendar timeline
- run history
- failures

### 6. Docs
Views:
- all docs
- by project
- by type
- recently generated

### 7. Projects
Views:
- all projects
- project overview
- milestones
- docs, memory, cron, deliverables, team

## Navigation principles

- keep top-level tools few and stable
- let projects cut across tools instead of hiding everything under a project-only tree
- show ownership everywhere
- make hidden system state visible
- optimize for Jordan scanning quickly
